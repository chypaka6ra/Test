# Анализ логики свадебного сайта - Макет 5

## Обзор технологии
Это сайт, созданный на платформе **Tilda** (конструктор веб-сайтов). 
Он представляет собой свадебный макет с фотогалереей, контактной информацией и формами обратной связи.

---

## Структура страницы

### Блоки контента (по типам):
- **T123** (2 блока) - основные контейнеры и прелоадер
- **T396** (8 блоков) - основные секции контента с артбордами (галерея, текст, изображения)
- **T463** (1 блок) - специальный блок
- **T678** (1 блок) - специальный блок

### Основные разделы сайта:
1. **Прелоадер** - загрузка страницы с анимацией
2. **Галерея фотографий** - скролируемые блоки с фото
3. **Информационные секции** - текст о услугах
4. **Формы обратной связи** - контактные формы
5. **Контакты** - информация для связи

## CSS файлы и их функции

### 1. **tilda-grid-3.0.min.css**
- **Назначение**: Адаптивная сетка макета
- **Функции**:
  - Определяет контейнеры и сетку (.t-container, .t-width)
  - Отзывчивость для разных экранов (320px, 480px, 640px, 960px, 1200px)
  - Базовые стили для блоков и элементов

### 2. **tilda-blocks-page102504056.min.css** 
- **Назначение**: Специфические стили для этой страницы (проект ID 6670519)
- **Функции**:
  - Кастомные цвета, шрифты, оформление
  - Стили для конкретных блоков (T396, T123, T463, T678)
  - Оформление галереи, текста, кнопок
  - Свадебная тематика (оттенки, декоративные элементы)

### 3. **tilda-animation-2.0.min.css**
- **Назначение**: Анимации элементов при скролле и загрузке
- **Функции**:
  - Fade in (появление из прозрачности)
  - Slide up/down/left/right (движение при появлении)
  - Zoom in/out (масштабирование)
  - Управление timing и easing функциями
  - `data-animate-style="fadeinup"` - элемент появляется с низу

### 4. **tilda-forms-1.0.min.css**
- **Назначение**: Стили для форм обратной связи
- **Функции**:
  - Оформление input полей, textarea
  - Стили кнопок отправки
  - Инпуты для имени, телефона, сообщения
  - Валидация и ошибки

### 5. **tilda-zero-form-errorbox.min.css**
- **Назначение**: Стили ошибок в формах (Zero-framework)
- **Функции**:
  - Красное оформление ошибок
  - Всплывающие сообщения об ошибках
  - Валидация на клиенте

### 6. **fonts.googleapis.com (Google Fonts)**
- **Назначение**: Внешние шрифты
- **Функции**:
  - Загружает красивые шрифты для заголовков
  - Обычно шрифты типа Montserrat, Open Sans, Playfair Display
  - Улучшает типографику свадебного дизайна

## JavaScript файлы и их функции

### 1. **jquery-3.6.0.min.js** (jQuery библиотека)
- **Назначение**: Основная JavaScript библиотека
- **Функции**:
  - DOM манипуляция (выбор, изменение элементов)
  - Обработка событий (клики, скролл)
  - AJAX запросы
  - Анимации
  - Кросс-браузерная совместимость

### 2. **tilda-scripts-3.0.min.js** (Tilda Core)
- **Назначение**: Основной движок Tilda
- **Функции**:
  - Инициализация блоков и элементов
  - Управление жизненным циклом страницы
  - Обработка данных из админпанели
  - Интеграция с другими модулями Tilda

### 3. **tilda-blocks-page102504056.min.js** (Страница-специфичный JavaScript)
- **Назначение**: Логика для конкретной страницы
- **Функции**:
  - Инициализация специфичных блоков
  - Обработчики событий для кнопок и ссылок
  - Скрипты для контактных форм
  - Интеграция с CRM (WhatsApp, Telegram)

### 4. **tilda-lazyload-1.0.min.js** (Ленивая загрузка)
- **Назначение**: Оптимизация загрузки изображений
- **Функции**:
  - Загружает изображения только при скролле в видимость
  - Улучшает производительность страницы
  - Уменьшает потребление трафика
  - `data-tilda-lazy="yes"` - включена на странице

### 5. **tilda-animation-2.0.min.js** (Анимации на скролле)
- **Назначение**: Триггеры для CSS анимаций
- **Функции**:
  - Отслеживает скролл страницы
  - Добавляет класс `t-animate_started` при появлении в видимости
  - Запускает CSS анимации (fade, slide, zoom)
  - Управляет timing анимаций

### 6. **tilda-zero-1.1.min.js** (Zero UI Framework)
- **Назначение**: Базовый UI фреймворк Tilda
- **Функции**:
  - Базовая интерактивность
  - Управление состояниями элементов
  - Кросс-браузерные утилиты

### 7. **tilda-forms-1.0.min.js** (Обработка форм)
- **Назначение**: Логика форм обратной связи
- **Функции**:
  - Валидация полей формы
  - Обработка отправки
  - Интеграция с Tilda CRM
  - Отправка данных на сервер
  - Показ благодарственного сообщения

### 8. **tilda-zero-forms-1.0.min.js** (Формы Zero Framework)
- **Назначение**: Продвинутые функции форм
- **Функции**:
  - Маскирование ввода (телефон, карта)
  - Кастомная валидация
  - Интеграция с расширенными CRM

### 9. **tilda-animation-sbs-1.0.min.js** (Scroll-Based Animation)
- **Назначение**: Анимация на основе положения скролла (SBS = Scroll Based)
- **Функции**:
  - Более сложные анимации, привязанные к прогрессу скролла

### 10. **tilda-zero-scale-1.0.min.js** (Адаптивное масштабирование)

- **Функции**:

- **Назначение**: Поддержка старых браузеров

## Поток выполнения страницы

### Этап 1: Начало загрузки (HTML Parse)
1. Парсинг HTML
2. Загрузка CSS (grid, animations, forms, custom styles)
3. Выполнение inline скриптов (helper functions)

### Этап 2: Блокирующие ресурсы
1. Загрузка jQuery
2. Загрузка Tilda полифиллов (если старый браузер)

### Этап 3: DOMContentLoaded событие
1. Выполнение функции `t_onReady` (helper function)
2. Инициализация Tilda движка (tilda-scripts-3.0.min.js)
3. Инициализация блоков страницы (tilda-blocks-page102504056.min.js)

### Этап 4: Параллельная загрузка (async)
1. Загрузка анимаций (tilda-animation-2.0.min.js)
2. Инициализация форм (tilda-forms-1.0.min.js)
3. Включение ленивой загрузки (tilda-lazyload-1.0.min.js)
4. Запуск аналитики (tilda-stat-1.0.min.js, Яндекс.Метрика)

### Этап 5: Интерактивность
1. Анимации при скролле (SBS анимации)
2. Обработчики кликов на кнопки и ссылки
3. Отправка форм на Tilda CRM
4. Отслеживание действий пользователя

## Ключевые функции и переменные

### Глобальные функции в inline скриптах:
- `t_onReady(func)` - ожидание DOMContentLoaded
- `t_onFuncLoad(funcName, okFunc, time)` - ожидание загрузки функции
- `t396_initialScale(t)` - масштабирование артборда
- `t396_getFieldValue(t, e, i, a)` - получение значения из data атрибутов

### Глобальные объекты:
- `window.allrecords` - контейнер всех блоков
- `window.TN_SCALE_INITIAL_VER` - версия масштабирования
- `window.dataLayer` - для Google Analytics
- `sessionStorage` - для кеша состояния посещения

### Data атрибуты для блоков:
- `data-tilda-page-id="102504056"` - ID страницы
- `data-tilda-project-id="6670519"` - ID проекта
- `data-animate-style="fadeinup"` - тип анимации
- `data-artboard-height` - высота артборда
- `data-record-type` - тип блока (396, 131, 463, 678)

## Особенности оптимизации

1. **Ленивая загрузка изображений** - экономия трафика
2. **Асинхронная загрузка скриптов** - не блокирует отображение
3. **Минификация CSS/JS** - меньше размер файлов
4. **Кеширование в sessionStorage** - быстрое повторное посещение
5. **DNS prefetch** для tildacdn.com и ws.tildacdn.com
6. **Fallback скрипты** - страховка при ошибках

## Основной процесс загрузки страницы

```
HTML парсинг
    ↓
Загрузка CSS → Отображение макета
    ↓
Выполнение inline скриптов (helpers)
    ↓
Загрузка jQuery (блокирует)
    ↓
DOMContentLoaded
    ↓
Инициализация Tilda (defer скрипт)
    ↓
Инициализация блоков и форм
    ↓
Параллельная загрузка JS (async)
    ↓
Готовность страницы
    ↓
Пользовательские события
    → Скролл анимации
    → Клики на кнопки
    → Отправка форм
    → Отслеживание аналитики
```
