🎨 Loading Screen (Two-Stage Animation)

➜ Stage 1: Счетчик (на загрузке) + Stage 2: Исчезание (на скролле)

Вы должны видеть прямоугольник со счетчиком 0-100%. После этого прокрутите страницу вниз.

📋 Как это работает:

  • ✓ STAGE 1 (Page Load): Прямоугольник появляется со счетчиком 0-100%
  • ✓ Скролл блокирован во время счетчика
  • ✓ После счетчика → скролл разблокирован
  • ✓ STAGE 2 (On Scroll): Используется Intersection Observer для отслеживания
  • ✓ Когда пользователь доскролит до #loading-screen-trigger → запускается исчезание
  • ✓ Прямоугольник скользит вверх и удаляется

✓ Что должно произойти:

Stage 1: Загрузка (На странице загружается)

  • ✓ На экране появляется прямоугольник размером 100% × 100%
  • ✓ Цвет: #FBF7EE (светло-бежевый)
  • ✓ В центре экрана отобразится счетчик: 0% → 100%
  • ✓ Счетчик анимируется ~2.1 секунды
  • ✓ После 100% прямоугольник плавно исчезает (fade out 0.5s)
  • ✓ Скролл БЛОКИРОВАН во время счетчика
  • ✓ После счетчика скролл РАЗБЛОКИРОВАН

Stage 2: Исчезание (При доскролле)

  • ✓ Прокрутите страницу вниз
  • ✓ Когда дойдете до элемента-триггера → прямоугольник начнет скользить вверх
  • ✓ Прямоугольник удаляется из DOM
  • ✓ Страница полностью доступна

🎯 Тестирование

Способ 1: Автоматическое (рекомендуется)

  1. Откройте DevTools (F12) → Console
  2. Обновите страницу (Ctrl+R или Cmd+R)
  3. Вы должны видеть прямоугольник со счетчиком 0-100%
  4. После счетчика скролл разблокируется
  5. Прокрутите страницу вниз до элемента "TRIGGER ANIMATION HERE"
  6. Прямоугольник скользит вверх и удаляется
  7. Наблюдайте логи в консоли

Способ 2: Ручной запуск

  1. Откройте DevTools (F12) → Console
  2. Запустить только счетчик: window.LoadingScreen.startCounter()
  3. Или запустить только исчезание: window.LoadingScreen.startHide()

💡 Ручное управление (Public API)

В консоли браузера вы можете использовать:

// Запуск этапов
window.LoadingScreen.startCounter() // Запустить счетчик (Stage 1)
window.LoadingScreen.startHide() // Запустить исчезание (Stage 2)

// Проверка статусов
window.LoadingScreen.isCounterComplete() // true если счетчик завершен
window.LoadingScreen.isHideStarted() // true если исчезание началось
window.LoadingScreen.isComplete() // true если все завершено

🔧 Технические детали

  • Архитектура: Two-stage (двухэтапная) анимация
  • Stage 1 Trigger: DOMContentLoaded (автоматически при загрузке)
  • Stage 2 Trigger: Intersection Observer (#loading-screen-trigger или ручной вызов)
  • Размер прямоугольника: 100% ширины × 100% высоты (position: fixed)
  • Цвет: #FBF7EE (светло-бежевый)
  • Счетчик (Stage 1): requestAnimationFrame для плавной анимации 0-100%
  • Длительность счетчика: 2.1 сек
  • Скролл блокируется: Во время Stage 1 (счетчик)
  • Скролл разблокируется: После счетчика (~2.5 сек)
  • Исчезание (Stage 2): CSS transform (translateY -120%) + transition 1.7s
  • Z-index: 9999 (поверх всех элементов)
  • Intersection Observer threshold: 0.1 (10% видимости триггера)

⚙️ Как интегрировать в проект

Stage 1 (Счетчик) - запускается АВТОМАТИЧЕСКИ при загрузке

Stage 2 (Исчезание) - запускается при доскролле (или вручную)

  1. Подключите скрипт loading-screen.js в конец body:
    <script src="assets/js/loading-screen.js"></script>
  2. Добавьте CSS:
    <link href="assets/css/loading-screen.css" rel="stylesheet">
  3. Для автоматического Stage 2: Добавьте триггер-элемент где нужно запустить исчезание:
    <div id="loading-screen-trigger"></div>
  4. Готово! Счетчик запустится сразу, исчезание - при доскролле

Для ручного управления:

// Запустить Stage 1 (если не запустился автоматически)
window.LoadingScreen.startCounter();

// Запустить Stage 2 (если нет триггер-элемента)
window.LoadingScreen.startHide();
