➜ Loading Screen Component Test

Если вы видите белый экран со счетчиком (0% → 100%), значит компонент работает!

✓ Что должно произойти:

  • ✓ На экране должен появиться прямоугольник размером 100% × 100%
  • ✓ Цвет прямоугольника: #FBF7EE (светло-бежевый)
  • ✓ В центре экрана отобразится счетчик: 0% → 100%
  • ✓ Счетчик будет анимироваться в течение ~2.1 секунд
  • ✓ После 2.5 сек прямоугольник начнет скользить вверх
  • ✓ Страница станет скролируемой через ~3.5 сек
  • ✓ Прямоугольник полностью исчезнет через ~5.3 сек
  • ✓ Страница будет доступна для просмотра

📊 Таймлайн

Время (сек) Действие
0.0 Прямоугольник появляется, счетчик начинает с 0%
2.1 Счетчик достигает 100%
2.5 Прямоугольник начинает плавно скользить вверх
3.5 Страница становится скролируемой
5.3 Прямоугольник удаляется из DOM

🎯 Тестирование

Для полноценного теста:

  1. Откройте DevTools (F12)
  2. Перейдите на вкладку Console
  3. Обновите страницу (Ctrl+R или Cmd+R)
  4. Наблюдайте логи появления/исчезания экрана
  5. Проверьте что счетчик плавно изменяется от 0 до 100%
  6. Убедитесь что после завершения страница становится доступной

💡 Ручное управление

В консоли браузера вы можете использовать:

window.LoadingScreen.isComplete() // true/false
window.LoadingScreen.isInitialized() // true/false
window.LoadingScreen.hide() // Принудительно скрыть
